# Banking System - Java

A simple console + GUI banking system I built to practice core Java concepts.

I built this as a junior developer to get better at OOP and data structures.

## What it does
- Create Savings and Cheque accounts
- Deposit / Withdraw with validation (no overdraft)
- Sort accounts by balance using bubble sort 
- Track transactions with 2D array
- Swing GUI for display and sorting

## Concepts practiced
- OOP: Abstract classes, Inheritance, Polymorphism, Encapsulation
- Data structures: ArrayList, Enum, 2D arrays
- Algorithms: Bubble sort
- Exception handling: try/catch for user input
- GUI: JFrame, JButton, JTextArea
