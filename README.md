# Banking System - Java

A simple console-based banking system built in Java for handling accounts, deposits, withdrawals and balance management.

## Features
- Create new bank accounts
- Deposit and withdraw money
- Check account balance
- View transaction history
- Secure login system

## Technologies Used
- Java
- NetBeans IDE
- Object-Oriented Programming (OOP)

## How to Run
1. Clone the repository: 
   git clone https://github.com/Karabo1308/BankingSystem.git
2. Open in NetBeans / IntelliJ / VS Code
3. Run `BankingSystem.java`
